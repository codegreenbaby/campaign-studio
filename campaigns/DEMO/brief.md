# DEMO · Lumen Tasks launch

Example campaign that ships with Campaign Studio. Lumen Tasks is a fictional task-planning app;
every number below is an example, not a fact about any real product.

- Goal: announce version 2.0 and drive free-trial sign-ups.
- Languages: en, de, ar (ar shows right-to-left layout).
- Formats: the six in `formats.json`.
- Offer: 20% off new annual plans with code LAUNCH20.
- Art direction: dark navy background with soft glows, blue accent, rising chart, a sprite that
  flies from bottom-left to top-right, numbers counting up on start.
